# Datepicker UI

A static datepicker user interface built with pure HTML and CSS. This project focuses on practicing layout, positioning, and styling techniques without any JavaScript functionality.

**Project Reference:** [roadmap.sh - Datepicker UI](https://roadmap.sh/projects/datepicker-ui)

---

## Overview

This is a beginner-friendly frontend project that recreates a simple datepicker component. It includes:

- Date input fields (day / month / year)
- Calendar icon button
- Month and year navigation controls
- Full calendar grid for a sample month (December 2022)

The design uses modern CSS features such as container queries (`cqw` / `cqh`) for responsive sizing and a clean, minimal layout.

---

## Technologies Used

- HTML5
- CSS3 (Flexbox, Container Queries, Custom Properties)

---

## Project Structure

```
.
├── index.html
├── style.css
└── assets/
    ├── date-svgrepo-com.svg
    ├── back.svg
    └── next.svg
```

---

## How to View

Simply open `index.html` in any modern web browser. No build step or server is required.

---

## Features

- Clean and centered layout
- Responsive sizing using container query units
- Separate input fields for day, month, and year
- Static calendar table with day headers
- Navigation buttons for previous/next month (visual only)

---

## Notes

This version is intentionally static. It serves as a solid foundation that can later be enhanced with JavaScript to make it fully interactive.

# رابط کاربری انتخابگر تاریخ

یک رابط کاربری استاتیک برای انتخاب تاریخ که فقط با HTML و CSS ساخته شده است. این پروژه روی تمرین چیدمان، موقعیت‌دهی و تکنیک‌های استایل‌دهی تمرکز دارد و هیچ قابلیت جاوااسکریپتی ندارد.

## نمای کلی

این یک پروژه سطح مبتدی فرانت‌اند است که یک کامپوننت ساده انتخابگر تاریخ را بازسازی می‌کند. شامل موارد زیر می‌شود:
